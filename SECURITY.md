# Security Policy

Crossmart stores marketplace credentials and order data, so we take security reports seriously.

## Reporting a vulnerability

**Do not open a public issue.** Report vulnerabilities privately by either:

- using [GitHub private vulnerability reporting](https://github.com/crossmart-io/crossmart-web/security/advisories/new), or
- emailing **hello@crossmart.io** with "Security" in the subject.

Please include a description, the steps to reproduce, the affected version, and the impact you expect.

We will acknowledge your report within 3 business days and keep you updated until a fix is released. We are happy to credit reporters who follow responsible disclosure.

## Supported versions

Crossmart is in early development. Only the latest commit on `main` receives security fixes.
